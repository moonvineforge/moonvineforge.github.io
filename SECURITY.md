# Security Policy

Moonvine Forge is a small static website hosted with GitHub Pages.

## Reporting a vulnerability

If you find a security issue, please do not open a public issue with exploit details.

Instead, contact the project maintainer privately through GitHub or by email if a contact address is listed on the website.

## Scope

Relevant issues include:

- exposed secrets
- unsafe third-party embeds
- malicious links
- broken privacy expectations
- supply-chain risks in website assets

General typos, layout bugs, and content suggestions can be reported through normal GitHub issues.
