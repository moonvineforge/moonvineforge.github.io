# Maintenance Notes

Moonvine Forge is a small static website. Most safe changes should be easy to review and easy to revert.

## Before changing public pages

- Check the page locally in a browser.
- Keep existing public URLs working.
- Do not remove the Tally form embed without replacing the submission path.
- Do not remove the visitor counter unless the replacement is ready.
- Keep legal pages reachable from the public site.

## Preferred pull request size

Small pull requests are easier to review. Prefer one focused change per pull request.
