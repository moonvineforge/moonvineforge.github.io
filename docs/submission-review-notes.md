# Submission Review Notes

Community submissions can be reviewed with a simple first-pass checklist.

## First-pass questions

- Is the idea understandable in one sentence?
- Does it create a meaningful choice?
- Can it be prototyped from simple effects?
- Does the theme support the mechanic?
- Would the idea still work if numbers changed?

## Possible outcomes

- Keep as inspiration.
- Convert into a prototype.
- Combine with another idea.
- Rename or simplify.
- Leave unused.
