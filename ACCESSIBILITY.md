# Accessibility Notes

Moonvine Forge should remain usable with keyboard navigation, small screens, and reduced-motion preferences.

## Current priorities

- Keep text readable against dark backgrounds.
- Preserve visible focus styles.
- Use descriptive link text.
- Avoid relying on animation alone.
- Keep page structure clear with headings and landmarks.

## Future improvements

- Review contrast on every new visual component.
- Add alt text for meaningful images.
- Test the Card Forge flow on mobile devices.
