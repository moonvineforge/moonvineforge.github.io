# Contributing to Moonvine Forge

Thanks for helping improve Moonvine Forge.

## Contribution style

Please keep contributions small and focused. A good pull request changes one clear thing, such as:

- improving wording
- adding an example card or relic
- fixing a responsive layout issue
- improving accessibility
- polishing metadata or documentation

## Website safety

Please avoid changes that break existing public pages, the Tally form embed, the visitor counter, or legal pages.

Before opening a pull request, check the changed page locally in a browser.
