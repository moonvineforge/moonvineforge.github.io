# Support

Moonvine Forge is an early-stage open-source website and community card forge.

## Questions

For general project questions, open a GitHub issue and choose the most fitting template.

## Card ideas

Please submit card, relic, enemy, status, and resource ideas through the Card Forge page instead of opening a GitHub issue.

## Bugs

Website bugs can be reported with the bug report issue template.

## Contributions

Small pull requests are welcome. Please read `CONTRIBUTING.md` before making larger changes.
